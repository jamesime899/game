# 🦴 ผจญภัยโลกกระดูกมหัศจรรย์ (The Wonder Bone Adventure)
### สื่อการเรียนรู้วิทยาศาสตร์แบบมีปฏิสัมพันธ์ (Interactive Web Game) สำหรับนักเรียนชั้นประถมศึกษาปีที่ 3

เว็บเกมการเรียนรู้วิชาชีพวิทยาศาสตร์ เรื่อง **"กระดูกของมนุษย์"** ออกแบบตามหลักจิตวิทยาเชิงบวกและการเสริมแรงทางบวก (Positive Reinforcement) สำหรับเด็กชั้น ป.3 ตอบผิดมีคำใบ้ช่วยคิดและให้ลองใหม่ได้ทันทีโดยไม่หักคะแนน พร้อมระบบส่งคะแนนเข้า Google Sheets อัตโนมัติ

---

## 🌟 ฟีเจอร์เด่นของเกม
1. **7 ด่านผจญภัยตามมาตรฐานหลักสูตร ป.3:**
   - ด่านที่ 1: ปราการกะโหลกศีรษะ (การปกป้องสมอง)
   - ด่านที่ 2: เกราะอกซี่โครงมหัศจรรย์ (ปกป้องหัวใจและปอด)
   - ด่านที่ 3: เสาค้ำหลังหรรษา (กระดูกสันหลังและการทรงตัว)
   - ด่านที่ 4: ไขปริศนาจำนวนกระดูก (กระดูก 206 ชิ้นในผู้ใหญ่)
   - ด่านที่ 5: สะพานข้อต่อเคลื่อนไหว (ข้อต่อและการงอแขนขา)
   - ด่านที่ 6: พลังอาหารเสริมสร้างกระดูก (แคลเซียม นม และปลาเล็ก)
   - ด่านที่ 7: ภารกิจดูแลรักษากระดูก (แสงแดดเช้า ออกกำลังกาย และท่าทาง)
2. **ระบบสุ่มตัวเลือกอัจฉริยะ (Dynamic Shuffle):**
   - ตัวเลือก 4 ช้อยส์ (ก, ข, ค, ง) สลับตำแหน่งใหม่ทุกครั้งที่เล่น
   - คำตอบที่ถูกต้องไม่ซ้ำตำแหน่งเดิม
   - ไม่มีการซ้ำซ้อนของคำตอบ
3. **ระบบเสริมแรงทางบวก:**
   - **ตอบถูก:** ได้รับคะแนน มีเสียงเอฟเฟกต์สดใส และป๊อปอัปความรู้เสริม (Bite-sized Facts)
   - **ตอบผิด:** แสดงป๊อปอัปคำใบ้จากน้องโบนนี่ ให้เด็กคิดวิเคราะห์และกดตอบใหม่ได้ทันทีโดย **ไม่หักคะแนน**
4. **รางวัลและเหรียญเกียรติยศ:**
   - 🥇 เหรียญทองคำ: ตอบถูกครบทุกข้อในครั้งเดียว
   - 🥈 เหรียญเงิน: แก้โจทย์สำเร็จโดยลองใหม่ 1-3 ครั้ง
   - 🥉 เหรียญทองแดง: มีความมุ่งมั่นพยายามจนผ่านครบทั้ง 7 ด่าน
   - มีพลุและคอนเฟตติเฉลิมฉลอง
5. **ระบบเสียงในตัว (Built-in Web Audio API):**
   - สังเคราะห์เสียงผ่าน Browser ไม่ต้องโหลดไฟล์ MP3 ภายนอก ทำงานได้รวดเร็วและออฟไลน์
   - มีปุ่มเปิด-ปิดเสียง (🔊/🔇) บันทึกการตั้งค่าอัตโนมัติ
6. **รองรับทุกอุปกรณ์ (Fully Responsive):**
   - ปุ่มใหญ่ ตัวอักษรอ่านง่าย สบายตา เหมาะสำหรับหน้าจอมือถือ แท็บเล็ต (iPad) และคอมพิวเตอร์

## 🚀 วิธีนำโปรเจกต์ขึ้น GitHub Pages

1. เข้าเว็บไซต์ [GitHub.com](https://github.com) แล้วสร้าง Repository ใหม่ (เช่น ตั้งชื่อว่า `bone-adventure-game`)
2. อัปโหลดไฟล์ทั้งหมดขึ้น Repository:
   - `index.html`
   - `style.css`
   - `script.js`
   - `google-script.js`
   - `README.md`
3. ไปที่เมนู **Settings** ของ Repository นั้น
4. เลือกหัวข้อ **Pages** (แถบด้านซ้าย)
5. ในส่วน **Build and deployment > Branch** ให้เลือก Branch `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอประมาณ 1 นาที จะได้ลิงก์เว็บไซต์ เช่น:  
   `https://<username>.github.io/bone-adventure-game/`
7. สามารถนำลิงก์หรือสร้างเป็น QR Code ให้นักเรียนสแกนเล่นในห้องเรียนหรือที่บ้านได้ทันที!
